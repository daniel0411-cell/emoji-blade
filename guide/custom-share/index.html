Custom Emoji & Share Link Troubleshooting

2026-11-12

Fix unexpected emoji inputs and distinguish generator build links, comparison links, arena challenges and local two-player entries.

Why is only one emoji used?

The game trims surrounding whitespace and uses the first grapheme cluster, not an entire sentence or a team of pasted emoji. In modern browsers, joined emoji and skin-tone sequences can remain one cluster. Browsers without grapheme segmentation fall back to the first Unicode code point, so complex sequences may be shortened. Enter one emoji, then check the displayed top before sharing.

An empty generator player field previews Unicorn (🦄); an empty rival field previews Diamond (💎). Enter an explicit character when you need an unambiguous shared setup.

Why do the ratings or artwork differ?

Known presets use fixed base ratings. Other normalized characters receive deterministic ratings in this version: entering the same normalized character again gives the same values. A similar-looking symbol, variation selector or joined sequence can be a different input. Font and operating-system artwork can also differ without proving that the saved character changed. Custom input is not an editor for independently setting mass, attack, speed or endurance.

Which link should I share?

Choose the link by its destination. A generator build opens the calculator; a generator comparison also restores the rival and opens the comparison panel. The local-duel action opens the arena with both characters in local 2P mode. The arena challenge restores a custom rival for solo practice. None of these provides remote multiplayer or a synchronized battle with another device.

Why did the link open solo practice?

An arena challenge contains emoji, rival, player style and the Hazard choice when enabled. It does not include local 2P mode, launch power, angle, stage, streak or a Boss encounter bonus. A generator comparison link also does not carry battle settings. To play together on one device, use the local-duel action. To return to solo progression, choose single-player and progression in the rival selector.

What if copying fails?

If clipboard access is denied or unavailable, the copy action offers a dialog with the full link. Copy that text manually; if you cancel the dialog, nothing has been shared. If no dialog appears, open the generator destination and copy its complete address, including the query after the question mark. Encoded characters such as %F0 are normal URL text: keep the link intact. Never add credentials or private data to a challenge URL.

Check a shared setup before playing

Open the link in a new tab and verify both displayed emoji, page type, mode and arena before launch. Re-enter any power and angle settings you intend to compare, since links do not save them. Compare base stats in the calculator; a selected Oni is not the larger boosted stage Boss. A link is a setup reference, not a replay, saved result or transfer of best streaks and badges.
