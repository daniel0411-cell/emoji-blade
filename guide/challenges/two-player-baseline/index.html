Two-Player Baseline: Same-Device Drill

A short same-device protocol for testing any pair before making a matchup claim or saving a share link.

Before you start

Player 1 and Player 2 configure in sequence on the same device. This mode does not advance the solo stage or add Boss bonuses.

Repeatable setup

  1. Choose a pair, set both powers to 70%, and write down both angles before launching. Keep the viewport fixed and leave Dash unused for the baseline.
  2. Keep the same viewport and top pair for the first comparison so the result is interpretable.
  3. Write down the launch settings, first contact, critical or Xtreme feedback, and remaining energy.

How to review the result

Run one repeat with the same settings, then vary one angle. Save the pair and settings in your notes. Share links select a configuration; they do not certify a winning strategy.
