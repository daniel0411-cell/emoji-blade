Moai vs Diamond: Endurance and Mass Trial

A two-player test for separating passive endurance from collision response when Moai and Diamond use the same starting conditions.

Before you start

This is a local practice comparison, not a measured ranking. Moai emphasizes endurance while Diamond emphasizes mass; their other ratings also differ, so the result cannot isolate one stat completely.

Repeatable setup

  1. Open the preselected local duel, set both tops to 70% power, and use the same angle on the first round. Record canvas size, first contact, critical feedback, and remaining energy.
  2. Keep the same viewport and top pair for the first comparison so the result is interpretable.
  3. Write down the launch settings, first contact, critical or Xtreme feedback, and remaining energy.

How to review the result

Swap left and right on a second round. Then change only one angle. Compare several rounds before describing a pattern; random criticals and collisions can dominate one result.
