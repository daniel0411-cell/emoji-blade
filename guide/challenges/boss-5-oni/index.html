Boss 5 Oni: Prepare, Observe, Retry

A repeatable first Boss trial: use the boosted Oni encounter, record the first collision, and change one launch variable at a time.

Before you start

Set up a solo Streak Mode run until stage 5. The encounter applies the game’s Boss bonus to Oni; the base Invader or a local 2P preset does not reproduce it.

Repeatable setup

  1. Use 70% power and -35° as Player 1’s starting trial. Keep the canvas size fixed, leave Dash unused, and watch whether the first contact causes a collision spike or only passive drain.
  2. Keep the same viewport and top pair for the first comparison so the result is interpretable.
  3. Write down the launch settings, first contact, critical or Xtreme feedback, and remaining energy.

How to review the result

If the top loses early, retry the same setup once before changing angle. Then change only angle or power and record the result. A single win does not prove a counter or a best build.
